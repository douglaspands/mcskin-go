# Claude Code Project Guidelines

Please strictly follow the rules and procedures defined in [AGENTS.md](AGENTS.md):
- **Architecture**: Go standard library only (zero external dependencies), cross-platform Linux/Windows/macOS (Apple Silicon arm64), deterministic output. Browser-native ES6 modules only (no npm/bundlers). This dependency-free rule binds the production Go binary and the frontend served by the embedded web server; development/test tooling (e.g. a devDependency-only `package.json` for browser-driven regression testing) MAY declare external dependencies when they meaningfully improve quality or efficiency, provided they are never bundled into `bin/mcskin` or `internal/web/static/`.
- **Token Economy & Modularity ("Nascem Otimizadas")**: All application files in `cmd/`, `internal/`, and `internal/web/static/js/` MUST stay under 300 lines and 15 KB. Third-party vendor libraries reside exclusively in `internal/web/static/vendor/`. Use `./scripts/test-compact.sh` for silent-on-success testing and the `token-guardian` skill to inspect file sizes. Offload verbose investigation loops to subagents.
- **Fast, Safe & Economical I/O & Commands**: Always prefer token-optimized flags: `git status -s`, `git log -n 3 --oneline`, `git diff --stat`, `git branch --show-current`, `wc -l <file>`, `head -n 25`, and `./scripts/test-compact.sh`. Read targeted line slices (`StartLine`/`EndLine`, 30–60 lines) instead of full files; find lines via `grep -n`; zero redundant re-reads. Use surgical contiguous block edits instead of whole-file rewrites. Keep command timeouts responsive (3000–5000ms).
- **Methodology & TDD**: Strict Test-Driven Development (TDD). Tests must be verified failing (RED) before implementing code (GREEN).
- **Unit Test Mocking**: All unit tests must be 100% mocked with zero external integration (use in-memory buffers/readers; no network or external process calls). Integration tests must be explicitly segregated.
- **Host & Environment Security**: Strictly confined to workspace root. Zero privilege escalation (`sudo`/`su`). Air-gapped test runs. Bounded 30s execution timeouts.
- **OpenSpec**: Use `/opsx-propose`, `/opsx-apply`, and `/opsx-archive` for feature lifecycles.
  - **First Step on Propose**: Before creating any feature branch, the harness MUST ensure `main` is checked out and updated from remote (`git checkout main && git pull origin main`), then create `git checkout -b feat/<nome_spec>` for rollback isolation.
  - **Apply Phase Boundary**: Stop upon PO/QA approval; never auto-archive or prompt for PR during `/opsx-apply`.
  - **Squash Merge or Pull Request ONLY after Archive**: All git updates (archive move, spec sync) MUST be committed directly on `feat/<nome_spec>` during `/opsx-archive` before PR creation. After archiving and committing, prompt user to choose between local squash merge into `main` (`git checkout main && git merge --squash feat/<nome_spec>`) or creating a GitHub Pull Request (`git push origin feat/<nome_spec> && gh pr create ...`).
  - **Post-PR & Main Protection Invariant**: Once the PR is created and returning to `main`, NEVER make any further commits on the feature branch, and **ABSOLUTELY NEVER commit directly to `main`**. All git updates must occur in the archive command.
- **Allowed Harmless Commands**: `go test ...`, `go build ...`, `go vet ...`, `go run ...`, `go fmt ...`, `go mod tidy`, `make ...`, `./scripts/test-compact.sh`, `./scripts/package-mac-app.sh`, `node scripts/capture-screenshots.mjs`, `node ...`, `uv ...`, `python3 ...`, `google-chrome ...`, `git status`, `git status -s`, `git diff`, `git diff --stat`, `git log`, `git log --oneline`, `git add`, `git commit` (on feature branches only), `git checkout -b feat/...`, `git checkout main`, `git pull origin main`, `git merge --squash ...`, `git push origin feat/...`, `gh pr ...`, `wc ...`, `diff ...`.
- **Environment & Runtimes (Zero Search / Token Preservation)**: Runtimes are managed via `asdf` (`.tool-versions` defines `golang 1.27.0`, `nodejs lts`, `python 3.14.7`) and `uv`. Never run discovery loops (`which`, `find /`) for tools. Go is at `/home/douglas/.asdf/shims/go`. Node is at `/home/douglas/.asdf/shims/node` (strictly zero global npm installs). Python is at `/home/douglas/.asdf/shims/python3` using `uv` (`/home/linuxbrew/.linuxbrew/bin/uv`) with mandatory local virtualenv (`uv venv .venv`; strictly zero global pip installs). Browser is `/usr/bin/google-chrome` (zero browser discovery).
- **Prohibited Destructive Commands**: Never execute direct commits to `main`, `rm -rf` outside build artifacts, `git push --force`, `git reset --hard`, `git clean -f`, or privilege escalation (`sudo`).
- **Governance**: State graph phases, max 3-iteration cap per failure, halt on repeated errors, token optimization.
